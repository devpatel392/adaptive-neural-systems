# Experiments

Each experiment gets its own folder, named `<id>-<short-name>` using the IDs in [../docs/research-plan.md](../docs/research-plan.md), for example `E1.1-numpy-mlp-digits/`.

An experiment folder contains:

- `config.yaml` or `config.json`: every hyperparameter, the seeds and the dataset split definition.
- `run.py`: a script that trains, evaluates and writes results. Reusable logic belongs in `src/adaptive_neural_systems/`, not here.
- `RESULTS.md`: a summary **generated by `run.py`**, recording the git commit, package versions, hardware and metrics as mean ± std across seeds.

Summary figures referenced by `RESULTS.md` go in the experiment's `figures/` folder and are committed. Raw outputs (per-run histories, checkpoints, logs) go to the git-ignored `runs/` folder at the repository root.
